
# Консольный To-Do List на Python

Простое, чистое и расширяемое приложение для управления задачами прямо в терминале.  
Сохраняет задачи в `tasks.json` рядом со скриптом — ничего не потеряется даже после перезапуска!


## Особенности

- Добавление, удаление и переключение статуса задач
- **Дата и время создания** каждой задачи
- **Дата и время выполнения** (автоматически при отметке «Выполнено»)
- Автоматическое сохранение в `tasks.json`
- Чистая **объектно-ориентированная архитектура** (ООП)
- Полное разделение ответственности:
  - `Task` — модель одной задачи
  - `TaskRepository` — работа с файлом
  - `TodoApp` — бизнес-логика
  - `ConsoleUI` — красивый консольный интерфейс
- Очистка экрана и удобная навигация
- Готово к расширению: дедлайны, приоритеты, теги, сортировка, GUI, база данных и т.д.

## Пример задачи в списке

```
1. Купить хлеб — Выполнено (создана: 22.11.2025 14:37, завершена: 22.11.2025 15:10)
2. Позвонить маме — Не выполнено (создана: 22.11.2025 16:20)
```

## Установка и запуск

1. Убедись, что установлен **Python 3.8+**
2. Сохрани код в файл `todo.py` (или скачай репозиторий)
3. Запусти в терминале:

```bash
python todo.py
```

> Файл `tasks.json` создастся автоматически при первом добавлении задачи.

## Почему этот To-Do лучше других?

- Никаких зависимостей — только чистый Python
- Полная совместимость с Windows, macOS и Linux
- Читаемый и понятный код — идеально для изучения ООП
- Легко модифицировать под себя
