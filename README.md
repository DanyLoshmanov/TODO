
# Консольный To-Do List на Python

Простое, мощное и красивое приложение для управления задачами прямо в терминале.  
Все данные сохраняются в `tasks.json` — ничего не потеряется даже после перезагрузки!

## Что уже умеет

- Добавление, удаление и отметка задач
- **Дата и время создания** каждой задачи
- **Дата и время выполнения** (автоматически при завершении)
- **Три уровня приоритета** с эмодзи:
  - High priority **Высокий**
  - Medium priority **Средний**
  - Low priority **Низкий**
- **Автоматическая сортировка**: сначала срочные задачи
- Полное сохранение в `tasks.json`
- Чистая **ООП-архитектура** с разделением ответственности
- Красивый интерфейс + очистка экрана
- Никаких внешних зависимостей — только чистый Python

## Пример вывода задач

```text
Ваши задачи (отсортированы по приоритету):
──────────────────────────────────────────────────────────────────────────────────────────
 1. Сдать отчёт директору — Не выполнено [High priority Высокий] (создана: 22.11.2025 09:15)
 2. Купить подарок на ДР — Не выполнено [Medium priority Средний] (создана: 22.11.2025 12:30)
 3. Полить цветы — Выполнено [Low priority Низкий] (создана: 21.11.2025 18:20, завершена: 22.11.2025 07:10)
──────────────────────────────────────────────────────────────────────────────────────────
```

## Установка и запуск

1. Убедитесь, что установлен **Python 3.8+**
2. Сохраните код в файл `todo.py`
3. Запустите:

```bash
python todo.py
```

Файл `tasks.json` создаётся автоматически при первой задаче.

## Почему этот To-Do — лучший в своём классе

- Полностью на чистом Python — без pip install
- Работает везде: Windows, macOS, Linux
- Идеальный пример ООП для изучения
- Максимально расширяемый — добавляй что угодно
- Красивый и понятный интерфейс
